# LLM Weather App

An Android weather and city-management application integrating OpenWeather data and Google Gemini for weather insights and natural-language theme customization.

Developed collaboratively for CS427: Software Engineering at the University of Illinois Urbana-Champaign, spring 2026.

## Features

- Account registration and login.
- City management with weather and map navigation.
- Weather information retrieved through OpenWeather.
- Gemini-powered weather insights.
- Natural-language interface theme customization.

## My Contributions

- **Implemented core Android interfaces** for city management and navigation, connecting city selections with weather and map views.
- **Integrated cross-activity communication** using Intent extras to pass user input and support natural-language theme customization.
- **Redesigned city-list interactions** to provide direct access to weather details and map views.
- **Developed and executed LLM-assisted JUnit tests** for login and registration workflows, using Gradle to validate application behavior.
- **Collaborated on integration and testing** through Git-based development, contributing to the delivery of the team application.
